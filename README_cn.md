感谢您选择 Pastes 程序。

Pastes 是一款跨平台的剪贴板管理器。Windows 上可以按 `Win+V` 唤出底部剪贴板历史面板，也可以点击托盘图标。程序运行时接管 `Win+V`，退出后恢复 Windows 原生剪贴板历史；不修改系统设置。若快捷键接管失败，会尝试 `Ctrl+Shift+V`，实际可用的快捷键会显示在面板底部和托盘菜单中。Linux 使用 `Ctrl+Shift+V`。

macOS 的初步支持版本编译后位于 `build/pastes.app`，双击即可启动并显示面板。
程序运行后，用 `Shift+Cmd+V`（`⇧⌘V`）唤出或隐藏面板，也可以点击菜单栏图标。
程序以菜单栏工具方式运行。面板可以出现在其他应用的全屏空间内，唤出时保留当前空间，
并优先使用前台应用窗口所在的屏幕。
切换应用或桌面空间时会收起面板，在新的空间需要再次按快捷键唤出。
面板贴住屏幕底边显示，并覆盖 Dock 所在区域。快捷键用于唤出运行中的面板；
从菜单选择退出后，需要重新打开程序。
macOS 的后台记录与自动粘贴支持仍不完整。

Pastes 保留最近 30 天的剪贴板历史。用左右方向键或 `Tab` / `Shift+Tab` 在可见卡片间前后循环浏览；按 `Ctrl+F` 进入搜索框，也可以直接输入搜索。按 `Enter`、双击卡片或按 `Ctrl+1` 至 `Ctrl+9` 取用对应条目。按住 `Shift` 可粘贴为纯文本，`Space` 预览，`Delete` 删除，`Ctrl+C` 仅复制到剪贴板。Windows 上取用条目后会尝试粘贴到唤出面板前的窗口；目标窗口无法恢复焦点时，内容仍会留在系统剪贴板。面板高度按所在屏幕自动确定，不支持拖动拉伸。

按 `Space` 打开与面板主题一致的预览窗口，可选择长文本并完整查看图片。按 `Esc` 或 `Space` 关闭，也可以用窗口底部的按钮复制或粘贴内容。

鼠标单击卡片选中，双击粘贴；横向拖动时卡片跟手移动，松手后有短距离惯性，再次按住即可停下。拖动或滚动到两端后可以继续拉出一小段距离，阻力逐渐增加，松开后弹回；滚轮平滑滚动，触控板保留系统原有的惯性距离。轻微移动仍视为单击。按住卡片向上拖动约三分之二张卡片的距离（140–200 逻辑像素），出现“松开即可删除”后松手即可删除；拖回去或未达到阈值时会回弹。整张卡片随鼠标移出面板边界，松手后上沿向后翻倒、收缩成亮线，再像老电视关机一样向中心收成小光点，散出一小簇短促烟花并熄灭。松手后的完整删除动画约半秒完成。

卡片上保留来源、类型与时间信息，使用 `Space` 预览。`Delete` 和右键菜单可以删除历史记录，原始文件不受影响；相邻卡片会平滑滑入空位。删除后 8 秒内可点击“撤销”或按 `Ctrl+Z` 逐条恢复刚删除的内容：从细线展开成卡片，缓缓落回卡槽，相邻卡片同时滑开让位，撤销不播放烟花或粒子。删除的翻转尚未结束时撤销，会从当前姿态反向返回；翻转结束后从细线开始恢复。

## 界面风格

以 Paste 的底部面板与横向卡片浏览为基础，Pastes 使用自己的叠卡图标、暖白与黑灰配色、青绿色选中描边和内容类型标签。浅色与深色主题可在设置中切换。界面由 C++ / Qt Widgets 实现，无 QML 运行依赖。

## 设置

从面板右上角菜单或托盘菜单打开“设置”，修改立即生效并自动保存：

- **界面主题**：浅色、深色，面板与弹窗同步切换。
- **快捷键提示**：显示或隐藏卡片下方的操作提示。
- **开机启动**：Windows 为当前账户注册启动项，路径带空格时也可使用；Linux 使用用户的 autostart 目录，关闭时覆盖系统安装的启动项。移动程序后需重新开启此选项。
- **暂停记录剪贴板**：取消正在等待记录的内容，并跳过后续复制。已有历史保留，可以继续取用；恢复后只记录之后的复制。暂停状态会显示在主面板与托盘提示中。
- **快捷键说明**：显示实际生效的唤出快捷键，以及粘贴、预览、搜索的操作方法。

“关于 Pastes”使用与设置一致的圆角窗口，显示图标、版本、作者、许可证和项目主页。历史仍在本机保存最近 30 天。

## 平台代码结构

界面与历史管理通过 `platform/` 的公共 C++/Qt 接口调用系统能力。
Windows、macOS、Linux 的原生实现分别位于对应子目录，共用 Qt 行为放在
`platform/desktop/`，由 CMake 选择当前系统的实现。
接口职责、线程约束和扩展方法见[平台结构说明](docs/platform-architecture.md)。
