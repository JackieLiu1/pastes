# 架构重构实施计划

## 目标与约束

将窗口、历史业务、剪贴板输入输出、持久化和操作系统适配分开，使依赖方向可以由构建目标和测试检查。
保持 C++17 / Qt 6.3 基线，不添加 Qt 版本兼容分支。保持 SQLite schema、MD5 输入、30 天保留期限、
来源图标、图片压缩、删除与原位置撤销、预览和原目标粘贴行为。

## 实施阶段

1. **数据边界**：将条目和 MIME 数据从卡片头文件中独立出来，统一所有权；为历史仓库定义接口。
2. **存储边界**：SQL 工作线程只接收值快照，不访问界面拥有的 MIME 对象；退出时排空写入并在所属线程关闭连接。
3. **业务边界**：历史服务管理去重、过期、撤销和异步请求身份；剪贴板控制器管理采集、暂停、复制和来源查询。
4. **呈现边界**：历史视图负责卡片、筛选、导航和动画编排；手势控制器负责拖动状态；主窗口只负责窗口、菜单和弹窗。
5. **工程边界**：按职责组织目录和 CMake 目标；应用入口集中组装依赖，增加自动依赖检查、回归测试和架构说明。

## 验收

- Windows Release 编译无错误、无新增警告，Qt 6.3 API 基线不提高。
- 核心与应用层不依赖 QWidget / QtSql / 系统 SDK，存储层不包含界面头文件。
- 测试覆盖格式优先级和哈希、去重和来源图标、30 天边界、首行及邻居变化后的撤销、
  重新复制后的撤销、迟到图片结果、数据库重载和关闭时的待处理写入。
- 原生剪贴板标记入库、重启加载、单实例冒烟验证通过。
- Linux / macOS 和 Ubuntu 20.04 + Qt 6.3 的实测范围单独说明，不以 Windows 结果代替。

异步请求身份保存在卡片动态属性。先前的编译警告修复仍在工作区，本次在这些修改上继续。
