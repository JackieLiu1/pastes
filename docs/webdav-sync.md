# WebDAV 同步

在「设置 → 同步」填写 HTTPS WebDAV **目录**地址、账号和密码，点击
「保存连接」或「测试连接」。多台设备填写同一目录后，开启自动同步。
服务器原有目录必须存在，Pastes 在其中创建自己的 `Pastes/v1/events/`。

- 按 item 同步文字、富文本的文字/HTML、HTTP(S) 链接和图片内容。
- 不上传文件或文件夹，也不上传文件条目里的本地 URL、文件内容和系统私有
  剪贴板格式。单独复制的一段路径文字仍然是普通文字。
- 同步默认关闭。首次开启逐条补齐本地历史，随后新增、重复制、来源图标变化
  和删除分别产生增量记录。操作后等待约 1.5 秒上传，空闲时每 30 秒检查远端；
  网络错误后等待 60 秒重试，也可手动同步。
- 远端条目恢复原始复制时间，在本地历史按时间排序；不会自动写入系统剪贴板，
  不会选中刚到来的卡片，不会绕过正在使用的搜索条件。
- 普通内容在本地和远端保留 30 天，收藏内容长期保留；取消收藏后按原始复制时间恢复清理。单条内容最多 20 MiB，图片最多 20 Mi 像素；
  超限条目跳过并在同步状态中说明。文件与文件夹是范围外内容，不视为失败。
- macOS 密码保存在应用本地数据目录的 `credentials/webdav/` 下，独立于历史数据库
  和同步缓存；目录权限为 `0700`，文件权限为 `0600`。内容是明文 JSON，由当前用户的
  文件权限保护，不使用钥匙串，不随 WebDAV 同步。升级自钥匙串版本后，在「设置 → 同步」
  重新保存一次 WebDAV 密码即可；应用不会读取或删除旧钥匙串记录，也不会触发其授权弹窗。
  Windows 继续使用凭据管理器，Linux 使用 Secret Service（需要 `secret-tool` / libsecret）。
  各平台均不把密码写进 QSettings、日志或命令行。
  密码框留空表示沿用已保存的密码。该版本使用 HTTPS 传输，**没有端到端加密**，
  WebDAV 服务端可以读取上传内容。不要使用公开或与他人共用的目录。
- 不跟随服务器重定向，不忽略 TLS 证书错误。请填写服务商提供的最终 WebDAV
  地址。仅本机回环地址允许 HTTP，用于开发测试。

## 按条目保存的协议

每次条目变化保存为一个不可变 JSON 文件：

```
Pastes/v1/events/<SHA-256 of record bytes>.json
```

记录包含协议版本、可移植内容标识、变更时间、原始复制时间、内容和可选来源图标。
收藏状态和最后一次收藏操作的时间也随文字、链接和图片同步；文件条目的收藏仅保存在本机。
新写入使用协议版本 4，保存复制、删除、来源观测、收藏、名称和位置各自的事件版本。
仍读取版本 1、2、3；旧图标按未知来源兜底，不从记录时间或 PNG 文本推断一次真实观测。
旧客户端不能正确表达这些语义，参与同一目录同步的设备需同时升级；旧客户端会报告不兼容。
图片是 PNG 字节；文件路径、SQL 数据库和设备凭据不在上传数据里。
同一内容的多次变化可以留下多个文件，最终展示只取最新的有效状态。

这不是全量数据库快照，也不是每轮重写一个共享历史文件。同步时用 Depth: 1
PROPFIND 获取条目文件名，只 GET 未缓存的文件，只 PUT 待上传的条目。
上传使用 If-None-Match: *；已有同名文件时验证其实际内容摘要。两台设备同时
写入不同条目不需要抢写同一个索引，因此不会覆盖对方的历史。

内容标识独立于原有数据库 MD5：文字按去空白后的 UTF-8，链接按 URL 列表，
图片按 RGBA 像素计算 SHA-256。接收时重新生成当前设备的本地 MD5。
复制事件以 `(physical, counter, device)` 的持久混合逻辑版本排序；同内容可以有多次
复制事件，界面的 `EntryId` 仍只是本进程内对象身份。本地 MD5、可移植内容 SHA-256
和复制事件身份各有用途，不能互换。收到远端状态时推进逻辑时钟；物理时钟回退，或
已知远端时钟稍快时，之后的本地操作仍排在已知操作之后。完全离线的并发操作按稳定版本顺序收敛。

复制与删除版本决定条目是否存在。补图标、修改收藏、重试和合并都不能制造新的复制事件，
也不能恢复已删除条目。只有明确重新复制或撤销会产生新的复制版本。
原始复制时间保留毫秒，用于显示和内容过期；删除标记另存实际删除时间，
不使用逻辑时钟推进后的时间延长保留期。

来源图标保存原始复制事件的观测版本、采集时间和补全阶段。原生通知到达时建立复制事件，
异步图标结果仍使用该事件；补全结果可以更新同一次观测的初始快照。
内部复制、继承和同步回传完整保留原观测，不刷新来源版本。
新的真实观测优先；旧来源和无来源的旧版图标仅作缺失兜底。
PNG 文本中的旧时间提示不再决定优先级。

收藏、名称和位置分别合并自己的操作版本；同时命名和调序不会互相覆盖。
合并规则不增加任何字段的操作版本，因此重试、重复投递和不同到达顺序不会制造新编辑。
旧版本记录超过本机当前时间五分钟仍被拒绝；版本 4 的逻辑顺序与显示时间分开校验。

普通删除使用不含剪贴板内容、保留内容标识与字段元数据的标记，保留 60 天，长于内容的 30 天寿命。
涉及收藏的删除标记长期保留，不包含剪贴板内容，避免离线设备恢复旧收藏。
取消收藏后过期的内容先生成这种标记，再清理旧的收藏内容；已被新状态替代的收藏
记录也会清理，不永久保留历史副本。
因此旧设备上线不会把已删除的旧条目恢复；明确重新复制或撤销会产生更新状态。
已配置设备在关闭网络同步期间删除条目或改变收藏状态，也会在本地留下待同步记录。
收藏名称和顺序也会在关闭网络同步时保留待同步记录。关闭同步不会删除远端内容。

SQLite 是历史和待同步状态的持久化依据，原 `item/data` 表保持不变。
`entry_meta` 保存毫秒时间、内容映射及字段版本，`event_clock` 保存设备身份和逻辑时钟，
`sync_events` 保存仍需保留的字段状态，`sync_sent`、`sync_applied` 按账户记录上传和接收进度。
替换旧历史、保存新历史和待上传状态在同一事务提交；失败时保留旧历史，不上传失败的新状态。
接收端也在同一事务保存合并结果和已应用标记，提交成功后才确认接收。
写入失败会显示错误，保留重试；网络请求结束不能单独触发“已同步”。

关闭网络同步仍记录本地复制、删除和收藏操作，恢复后发送已提交状态。
待同步状态会压缩已被覆盖的旧版本并按保留期清理，不永久保留已过期的普通内容。
独立的 `sync/` 目录只作按账户隔离的网络缓存，可由数据库和远端重建。
缓存中的“来自本机”不代表“已应用到历史”，缺失的数据库历史仍可从缓存恢复。
空的远端目录不会被解释为删除本地历史；缺失的服务端记录可由持久状态补回。

完整性、格式、图片像素和长度校验通过后才提交历史；未知协议或损坏数据报告失败。
目录列表上限为 20,000 条。收藏旧记录只有在覆盖它的合并状态已可靠保存并上传后才清理。
过期内容由下一次成功同步清理，不保证离线期间服务器立即删除。

## 实现边界

- `application/syncservice.h`：设置页使用的同步接口、凭据存储接口。
- `core/synccontent.*`：可移植内容、值快照、身份、格式校验。
- `sync/webdavsync.*`：连接历史服务，调度同步，处理状态和设置。
- `sync/webdavworker.*`：独立线程内执行网络、缓存和确定性合并；仅上传已提交状态。
- `platform/*/secretstore.*`：平台密码存储；窗口代码不引用系统密码 API。
- `platform/localcredentialstore.cpp`：本机凭据文件，限制权限、按账号隔离并原子替换；
  macOS 使用这一实现，启动读取不依赖系统授权。
- `HistoryService::applySynced`：等待此前本地写入，按内容合并并通过仓库提交；不直接操作 SQL 或剪贴板。

QtNetwork 对象在工作线程创建和使用，跨线程只传值。缓存索引只持有元数据；
已知的持久记录按 ID 查询，已应用的远端记录不会在每次轮询时重新解码。设置切换会取消旧连接的请求，
旧回调不能向新的账号会话交付条目。

## 验证

`webdav_contract` 使用本机回环假服务器和临时目录，检查逐条上传、重复轮询
不重传内容、按复制时间恢复、删除与重新复制、离线重启、两设备合并、文件排除、
密码独立保存、关闭同步后删除、图片像素恢复、认证失败、重定向拒绝、损坏内容和
读写删除连接测试；本机密码存储还检查账号隔离、文件权限、损坏和写入失败、独立进程
重启读取，以及使用已保存密码恢复自动同步。`settings_contract` 检查分页、密码遮蔽和操作分发；
`historyview_contract` 检查远端到达时保留选择及搜索。

这些验证不需要、也不连接用户的真实 WebDAV 账户。不同服务商、Windows 和 Linux
系统密码存储仍需对应环境集成验证。

`eventstate_contract` 检查时钟回退、重放和字段合并排列。
`syncordering_contract` 使用真实 SQLite 和本机假服务器覆盖数据库到协议的毫秒精度、
空历史切换账户、缓存恢复缺失历史、关闭同步后的重新复制、迟到图标与删除、
SQL 故障不确认及重试、时钟偏差后的新来源、替换事务回滚、无缓存重启和离线收藏。
所有故障注入和数据删除仅作用于临时测试目录。
