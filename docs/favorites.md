# 内容收藏

点击卡片右上角星标，或在卡片右键菜单选择「加入收藏」。顶部「收藏」仅显示
收藏条目，搜索、方向键、数字快捷粘贴、预览和删除继续作用于当前可见条目。
「剪贴板历史」显示全部条目，包括收藏。

收藏长期保留，不参加普通历史的 30 天清理。取消收藏不会修改原始复制时间：
尚未过期的内容仍在历史里；已经过期的内容立即清理。再次复制同一内容会保留
收藏状态，并正常更新复制时间。手动删除仍可删除收藏，撤销会恢复收藏状态。

收藏状态保存到独立的 `favorite` 表，包含内容 MD5、是否收藏和最后修改时间；
既有 `item` / `data` 表结构不变。图像按内容去重时继承收藏，保留最新的收藏
操作时间，不依赖临时文件路径。数据库工作线程只接受值快照，收藏更新不重新
编码或写入剪贴板内容。

开启 WebDAV 后，文字、链接和图片的收藏状态跟随内容同步；文件和文件夹仅
保存在本机。关闭网络同步期间的收藏操作也会在已配置的账户缓存中排队。
收藏记录使用协议版本 2，所有参与同步的设备需升级，详情见
[WebDAV 同步](webdav-sync.md)。

验证覆盖收藏与普通历史的保留差异、取消收藏、重新复制、删除/撤销、数据库
重启及关闭时排空、图像去重后的收藏继承、筛选/搜索/选择/数字快捷粘贴，以及
两设备同步、离线重启、过期取消收藏和旧设备恢复。macOS 原生菜单另行检查
加入收藏和取消收藏的动作交付，界面检查浅色、深色和空收藏状态。
